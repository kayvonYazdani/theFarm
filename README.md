# The Farm

The active application is [The Farm 3](theFarm%203/README.md): a macOS-oriented
Python pipeline for selecting, captioning, editing and optionally publishing
vertical video highlights.

Start with its [setup and usage guide](theFarm%203/README.md). The production entry
point is `theFarm 3/run.py`; dependencies are listed in
[requirements.txt](theFarm%203/requirements.txt).

Shared environments, credentials, model installations and media remain local and
are excluded by the root `.gitignore`. Review production upload and cleanup
settings before running. No application license has been selected yet; third-party
licenses and media rights still apply.
